# RepDex

A comprehensive Pokédex for Pokémon GO: tick off what you've caught across 19 dexes (Caught, Lucky, Shiny, Shadow, Dynamax, Costumes and more), on phone or desktop.

- **Design:** [docs/DESIGN.md](docs/DESIGN.md)
- **Setup:** [docs/SETUP.md](docs/SETUP.md)

## Stack

Next.js (PWA) · Supabase (Postgres + auth) · Vercel · GitHub Actions

## Layout

| Path | What |
| --- | --- |
| `src/lib/dexes.ts` | Dex definitions and selection rules |
| `src/app/` | Pages: sign-in, dex overview, dex grid, settings |
| `supabase/migrations/` | Database schema and security rules |
| `supabase/seed/` | Pokémon list, generated by `scripts/build_seed.py` |
| `Images/` | Pokémon images, synced nightly from PokeMiners/pogo_assets |

## Local development

```
cp .env.example .env.local   # fill in the Supabase URL and key
npm install
npm run dev
```
