# Type icons

One icon per Pokémon type, named after the type in lowercase, as PNG:

normal.png, fire.png, water.png, grass.png, electric.png, ice.png, fighting.png, poison.png, ground.png,
flying.png, psychic.png, bug.png, rock.png, ghost.png, dragon.png, dark.png, steel.png, fairy.png

They're shown next to the type name on the Pokémon page (about 16 px; a square image looks best).
A type without a file shows its name only.
